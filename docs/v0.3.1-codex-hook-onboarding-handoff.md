## 1. 本轮已完成

- `init codex` / `init all` 只接受目标 Git 仓库根目录，并兼容 linked worktree。
- Codex Hook bundle 可以显式刷新；Windows 使用 `ReplaceFileW`，Linux 使用
  `RENAME_EXCHANGE` 保留被替换文件。
- 被替换文件进入项目本地 `.tmp/agenttoolgate/recovery/`，不再自动删除。
- `up` 在服务启动后发布实际 loopback endpoint 和当前二进制路径；启动失败会恢复原
  control。
- `hook control off` 不保留 endpoint 或 executable，避免临时二进制失效后误触发
  fail-closed。
- 已覆盖 Python 3.10、非默认端口、旧 adapter 兼容、失败回滚和 Codex allow no-op。
- Codex allow 仍是零输出 no-op；高风险 `deny` 仍保守阻断，未修改 Guard Core、policy、
  approval 或风险判定。

### P1-B：目标仓库本地忽略 ATG 运行目录

父目录 symlink / junction 的 TOCTOU 仍按 P2 guardrail 边界记录，不要为了这一项把 ATG
扩展成 OS sandbox。

## 6. 本地验证环境注意事项

Go 缓存可以放在仓库 `.tmp`，但 `GOTMPDIR` 和 Python `TEMP` 不要放进被测 Git 仓库，
否则测试临时目录可能向上识别到真实项目 control：

```powershell
$env:GOCACHE='<repo>/.tmp/go/build'
$env:GOMODCACHE='<repo>/.tmp/go/mod'
$env:GOTMPDIR='<workspace-parent>/.tmp/AgentToolGate-public-go'
$env:TEMP='<workspace-parent>/.tmp/AgentToolGate-public-python'
$env:TMP=$env:TEMP
```

下一轮不得为减少误拦而削弱 Guard Core，也不得把 Codex allow 改回显式
`permissionDecision=allow` 或透传 `updatedInput`。
