## 1. 冻结结论

`v0.3.1` 与已通过验收的 `v0.3.1-rc1` 指向同一产品提交：

```text

```

正式标签没有指向后续文档提交，也没有移动或覆盖已有 RC 标签。自 2026-08-12 起，
`v0.3.1` 是当前稳定版本，重点补齐 Codex 项目级 Hook 的安装、信任、诊断和运行时接入：

- `init codex` / `init all` 安装项目 TOML 和自包含 Hook bundle。
- `init codex --refresh-hooks` 安全刷新 adapter/Core，并保留 recovery 文件。
- `up` 在成功监听后发布真实 loopback endpoint 和当前 executable。
- `doctor --dir` 分开报告项目文件、运行模式和两层信任要求。
- Hook control、SQLite、recovery 和 Python 缓存不污染目标仓库。

AgentToolGate 仍然是工具治理网关和客户端 Hook guardrail，不是 OS sandbox、EDR 或完整
DLP。

本机结果。Linux 的正式发布结论来自同一标签的原生 Ubuntu runner。
