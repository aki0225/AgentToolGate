## 1. 发布范围

`v0.4.1` 是基于 `v0.4.0` 的日常使用可靠性补丁，不扩展 ATG 的安全边界，也不把
guardrail 描述成 OS sandbox 或完整 enforcement boundary。主要变化是：

- 项目初始化会把 Hook control、recovery 和 pending audit 运行态加入仓库本地
  `info/exclude`，避免它们污染 `git status`。
- `dry-run` 能正确识别绝对仓库根目录的破坏性删除，并生成高风险预览。
- OTLP exporter 默认关闭，只有显式配置 endpoint 时才启用，减少新安装环境的无关连接
  和错误噪音。

完整差异见
[`v0.4.0...v0.4.1`](https://github.com/aki0225/AgentToolGate/compare/v0.4.0...v0.4.1)。

## 5. 发布判断

`v0.4.1` 已达到补丁版本正式发布条件，并成为当前稳定版。`v0.4.0` 的原始验收记录继续
作为历史快照保留，不回写其 run、附件、Hash 或当时的验收结论。

本结论不改变项目边界：ATG 仍是工具调用治理网关和客户端 Hook guardrail；Hook 未加载、
未信任、被绕过、处于 `off` / `dry-run` 或未覆盖工具路径时，没有 ATG 实时阻断。
