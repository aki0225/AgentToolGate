# v0.4.2 Python 3.14 Hook 兼容修复计划

> 计划日期：2026-08-17
>
> 基线提交：`f9b82cf09e75f14a1738c3143ce41b5fcda863ff`
>
> 状态：实施中

## 1. 问题

AgentToolGate 当前文档声明项目 Hook 支持 Python 3.10+。在 Python 3.14.3 上，
`pathlib.Path.resolve()` 不再因路径字符串包含 NUL 字符而立即抛出异常，导致
`cwd = "bad\u0000cwd"` 没有进入既有的异常输入分支：

- `live` 会继续尝试调用 Go CLI，而不是在调用前直接保守拒绝。
- `dry-run` 会生成一条本不应存在的本地预览。
- Codex 和 Claude Hook 各有 2 项异常输入回归测试失败。

同一测试在 Python 3.12.13 和远端固定的 Python 3.13 环境通过。现有路径仍未观察到
高风险动作被放行，但实现行为已经偏离公开的异常输入合同，因此必须按产品缺陷处理。

## 2. 目标

- 在依赖 `pathlib` 或操作系统路径行为之前，显式拒绝包含 NUL 的工作目录。
- Codex、Claude 和发布包内嵌 Codex Hook 保持一致。
- `live` 异常输入不调用 Go CLI 或后端，并返回最小化拒绝结果。
- `off` / `dry-run` 异常输入继续保持 no-op，不写预览或 pending audit。
- CI 同时覆盖最低支持版本与 Python 3.14，防止兼容声明再次漂移。
- 不改变正常路径发现、低摩擦 fast path、Guard 决策、审批或审计语义。

## 3. 方案取舍

### 采用方案：入口显式校验

在 `find_repo_root()` 的路径解析入口检查 NUL 字符，发现后抛出 `ValueError`，继续复用
既有 `find_repo_root_safely()` 和 `main()` 异常处理。

选择原因：

- NUL 在支持平台上都不是合法路径字符。
- 不依赖 Python 小版本或操作系统对 `pathlib` 的隐式异常行为。
- 变更集中，不需要修改 Guard Core 或后端协议。

### 不采用：限制 Python 版本

把支持范围临时改为 Python 3.10–3.13 可以绕开测试，但会让已经安装 Python 3.14 的
用户无法使用，而且没有解决输入校验根因。

### 不采用：在 Go CLI 或后端兜底

异常工作目录不应离开 Hook 输入边界。继续调用下游会扩大行为差异，也违反现有测试对
“异常输入不调用 Go CLI / 后端”的约束。

测试：

- `.codex/hooks/test_agent_guard_pretool.py`
- `.claude/hooks/test_agent_guard_pretool.py`
- 保留嵌入式 Codex Hook 与仓库 Hook 字节一致性检查。

CI：

- 增加轻量 Python Hook 兼容矩阵：
  - Ubuntu / Python 3.10
  - Ubuntu / Python 3.14
  - Windows / Python 3.14
- 现有完整评估继续使用 Python 3.13。
- 本轮只更新当前 CI 中触发 Node.js 20 弃用警告的官方 Actions，不改 Release 打包逻辑。

## 5. 验收标准

必须通过：

1. Python 3.12：
   - Codex Hook 51 项以上全部通过。
   - Claude Hook 64 项以上全部通过。
2. Python 3.14：
   - 两套 Hook 测试全部通过。
   - `find_repo_root("bad\u0000cwd")` 明确失败。
   - `find_repo_root_safely("bad\u0000cwd")` 返回 `None`。
3. 后端：
   - `go test ./...`
   - `go vet ./...`
4. CI workflow：
   - YAML / actionlint 校验通过。
   - 新矩阵只运行 Hook 兼容测试，不重复完整 Go / 前端流水线。
5. 发布：
   - 因产品 Hook 和内嵌资产发生变化，至少完成一次 Windows release build + smoke。
6. 仓库：
   - `git diff --check`
   - 不包含真实密钥、个人路径或 provider 信息。

## 6. 非目标

- 不新增 Guard 规则。
- 不改变 Codex `ask` 保守映射为拒绝的行为。
- 不重新录制真实 Codex 五场景。
- 不创建或移动 `v0.4.2` 标签。
- 不发布 GitHub Release；只有补丁合并、远端 CI 通过和正式包验收后才能单独发版。
